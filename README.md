# Visualizador de recorridos de Euler

Visualizador paso a paso del algoritmo de Hierholzer, hecho para el trabajo práctico de Matemática Discreta y Autómatas (UAI).

Tiene dos casos:

- **Ejemplo del informe:** dos triángulos que comparten un vértice.
- **Barrio de la UAI:** la ruta de un camión recolector por las calles que rodean la sede de Lomas de Zamora, con datos de OpenStreetMap.

Muestra cinco fases: el dígrafo, el balance de cada vértice, las pasadas extra, la construcción del circuito con Hierholzer y el recorrido completo.

Teclas: flechas para cambiar de fase, espacio para pausar, R para repetir, 1 y 2 para cambiar de caso.

Datos de calles © colaboradores de OpenStreetMap (ODbL).
